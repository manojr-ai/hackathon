# HealthGPT Care Gap Trust Planner
**Track 2: Medical Desert Planner | DAIS 2026 Hackathon**

## 🎯 Project Overview

The **HealthGPT Care Gap Trust Planner** is a facility-centric healthcare planning system that identifies care gaps across India using evidence-based trust scoring. Unlike traditional health analytics that rely on assumed capabilities, this system extracts and validates facility capabilities from rich text evidence (descriptions, specialties, procedures, equipment) to provide transparent, explainable care gap assessments.

### Key Innovation: Evidence-Based Trust Scoring
- **Strong Evidence**: Multiple supporting fields + specific procedures/equipment
- **Partial Evidence**: Mentioned in description/specialty but lacks detail
- **Weak Evidence**: Single field mention with limited support
- **Suspicious**: Contradictions or implausible combinations
- **No Claim**: No evidence found (filtered out)

#### 1. `workspace.healthgpt.facilities_bronze`
**Purpose**: Raw facility data from Virtue Foundation dataset  
**Row Count**: 10,088 facilities  
**Key Columns**:

- `description` - Rich text description (main evidence source)
- `specialties` - JSON array of specialties
- `procedure` - JSON array of procedures offered
- `equipment` - JSON array of equipment available
- `capability` - JSON array of capability claims
- `source_urls` - Data provenance

**Usage**: Traceability, data lineage, raw data inspection

---

#### 2. `workspace.healthgpt.facilities_silver`
**Purpose**: Cleaned, standardized, deduplicated facility data  
**Row Count**: ~10,088 unique facilities  
**Key Columns**:
- `facility_id` - Primary key
- `facility_name` - Cleaned name
- `state` - Standardized (UPPERCASE)
- `city` - Standardized (Title Case)
- `pin_code` - Numeric only
- `latitude_clean`, `longitude_clean` - Validated coordinates
- `specialties_array` - Parsed JSON array
- `procedure_array` - Parsed JSON array
- `equipment_array` - Parsed JSON array
- `capability_array` - Parsed JSON array
- `evidence_text` - Combined text for keyword search
- `completeness_score` - Data quality score (0-100)

**Usage**: Primary source for evidence extraction, app filtering

---

#### 3. `workspace.healthgpt.facility_capability_evidence`
**Purpose**: Extracted capability claims with supporting evidence  
**Row Count**: ~20,000-50,000 facility-capability pairs  
**Key Columns**:
- `facility_id` - Links to facilities_silver
- `capability_id` - One of 7 capabilities (maternity, icu, nicu, etc.)
- `capability_name` - Human-readable name
- `evidence_count` - Number of evidence sources found
- `field_coverage` - Number of distinct fields with evidence (1-5)
- `avg_confidence` - Average confidence score (0.0-1.0)
- `evidence_fields` - Array of fields where evidence found
- `evidence_keywords` - Array of matched keywords
- `evidence_contexts` - Array of text excerpts (citations)

**Usage**: Evidence detail screen, trust scoring input, citation display

---

#### 4. `workspace.healthgpt.facility_trust_scores`
**Purpose**: Trust-scored facility-capability pairs  
**Row Count**: Same as evidence table  
**Key Columns**:
- `facility_id`
- `capability_id`
- `trust_signal` - **strong | partial | weak | suspicious**
- `confidence_score` - Numeric confidence (0.0-1.0)
- `evidence_summary` - JSON with field breakdown
- `review_priority` - high | medium | low
- `needs_verification` - Boolean flag

**Trust Signal Logic**:
```python
STRONG (0.9):
  - 3+ supporting fields
  - Includes procedures OR equipment
  - Example: Maternity in description + obstetrics specialty + C-section + incubator

PARTIAL (0.6-0.7):
  - 2+ supporting fields
  - Missing procedure/equipment detail
  - Example: ICU mentioned + critical care specialty

WEAK (0.3-0.4):
  - Single field mention
  - Example: Dialysis only in capability array

SUSPICIOUS (0.1):
  - Contradictions detected
  - Implausible combinations
```

**Usage**: Care gap map coloring, facility detail cards, review queue

---

#### 5. `workspace.healthgpt.care_gap_by_geography`
**Purpose**: Aggregated care gap scores by geography and capability  
**Row Count**: ~2,000-5,000 (state/city × capability combinations)  
**Key Columns**:
- `state`, `city` - Geographic identifiers
- `capability_id` - One of 7 capabilities
- `geography_type` - state | city | pin_code
- `gap_score` - Care gap score (0-100, higher = worse)
- `confidence_level` - high | medium-high | medium | low
- `total_facilities` - Total facilities in geography
- `strong_facilities` - Count with strong evidence
- `partial_facilities` - Count with partial evidence
- `weak_facilities` - Count with weak evidence
- `suspicious_facilities` - Count with suspicious claims
- `avg_confidence_score` - Average confidence
- `risk_category` - critical | high | moderate | low
- `review_priority` - high | medium | low

**Gap Score Formula**:
```python
trust_weighted_facilities = 
  (strong * 1.0) + (partial * 0.6) + (weak * 0.3)

gap_score = max(0, 100 - (trust_weighted_facilities * 10))

# 100 = severe gap (no facilities)
# 0 = good coverage (many strong facilities)
```

**Usage**: Overview screen, care gap map, scenario planning

## 🎨 Streamlit App: 6 Screens

### Screen 1: Overview / Gap Command Center
**Data Source**: `care_gap_by_geography`

**Features**:
- **Gap Score Card**: 0-100 score with color coding
- **Confidence Level Badge**: High/Medium/Low
- **Evidence Donut Chart**: Strong/Partial/Weak distribution
- **Top Care Gaps Table**: Sortable by state/capability
- **Recommended Actions List**: Prioritized next steps

**Query Example**:
```python
gaps_df = spark.sql("""
  SELECT state, capability_id, gap_score, confidence_level,
         strong_facilities, partial_facilities, weak_facilities
  FROM workspace.healthgpt.care_gap_by_geography
  WHERE geography_type = 'state'
    AND risk_category IN ('critical', 'high')
  ORDER BY gap_score DESC
  LIMIT 20
""")
```

### Screen 2: Care Gap Map
**Data Source**: `facility_trust_scores` + `facilities_silver` (lat/long)

- **Interactive Map**: Plotly or Folium

  - 🟢 Green: Strong evidence facilities
  - 🟡 Yellow: Partial evidence
  - 🔴 Red: Weak/Suspicious
- **Filters**: State, City, Capability
- **Click**: Drill into facility detail

**Query Example**:
```python
map_data = spark.sql("""
  SELECT f.facility_id, f.facility_name, f.state, f.city,
         f.latitude_clean, f.longitude_clean,
         t.capability_id, t.trust_signal, t.confidence_score
  FROM workspace.healthgpt.facilities_silver f
  JOIN workspace.healthgpt.facility_trust_scores t
    ON f.facility_id = t.facility_id
  WHERE f.latitude_clean IS NOT NULL
    AND t.capability_id = 'maternity'
```

### Screen 4: AI Gap Brief (OpenAI Integration)
**Data Source**: Aggregated from `care_gap_by_geography` + `facility_trust_scores`

**Features**:
- **Structured Prompt**: Send JSON with gap scores, evidence distribution
- **LLM Output Schema**: JSON with fields:
  - `finding`: Summary of care gap
  - `rationale`: Why this gap is likely real
  - `uncertainty`: What's uncertain / needs verification
  - `recommended_actions`: Prioritized list
  - `facilities_to_verify`: List with facility IDs
- **Citation Display**: Link findings to source data
- **Export**: PDF/Word report

**Prompt Template**:
```python
prompt = f"""
You are a healthcare planner analyzing care gaps. Based on the following STRUCTURED DATA ONLY:

Geography: {state}, {city}
Capability: {capability_name}
Gap Score: {gap_score}/100
Confidence: {confidence_level}
Facilities: {total_facilities} total
  - Strong evidence: {strong_facilities}
  - Partial evidence: {partial_facilities}
  - Weak evidence: {weak_facilities}

Generate a care gap brief in JSON format:
{{
  "finding": "...",
  "rationale": "...",
  "uncertainty": "...",
  "recommended_actions": ["..."],
  "facilities_to_verify": ["..."]
}}

Do NOT hallucinate facility names or data not provided.
"""
```

### Screen 5: Scenario Planner (What-If)
**Data Source**: `care_gap_by_geography` + `planner_scenarios`

**Features**:
- **Baseline Display**: Current gap score + confidence
- **Scenario Builder**:
  - **Action 1**: Verify weak claims → upgrade N facilities to strong
  - **Action 2**: Add new facility → increase strong count
  - **Action 3**: Reject suspicious → decrease facility count
  - **Action 4**: Increase capacity → adjust weighted score
- **Projected Impact**: New gap score + confidence after action
- **Save Scenario**: Persist to `planner_scenarios` table
- **Compare Scenarios**: Side-by-side view

**Calculation Logic**:
```python
# Baseline
baseline_strong = 5
baseline_partial = 10
baseline_weak = 8
baseline_trust_weighted = (5*1.0) + (10*0.6) + (8*0.3) = 13.4
baseline_gap = 100 - (13.4 * 10) = 0  # Actually good coverage

# Scenario: Verify 5 weak → upgrade to strong
projected_strong = 5 + 5 = 10
projected_partial = 10
projected_weak = 8 - 5 = 3
projected_trust_weighted = (10*1.0) + (10*0.6) + (3*0.3) = 16.9
projected_gap = 100 - (16.9 * 10) = 0  # Even better
```
